Three rows belong here

  • S and M are different sizes. They share a product handle but remain separate variants.
  • The back image needs its own row. It adds a photo, not another product.

One decision is needed

Line 5 repeats size S for the same product, with a different SKU and price. Check the original product data before choosing a correction. The report does not choose which row to delete.

A small, reviewed correction milestone

  1. Inspect an export

    Agree a catalogue scope and price. Review a product export to find conflicting records, split sizes and missing information.

  2. Approve the change map

    See exactly what is proposed and which questions remain. Confirm the source of truth before a corrected file is prepared.

  3. Test an agreed batch

    Review the prepared file against acceptance checks. Any store import is a separate approved step, with backup and reversal needs addressed.

Start with a clear scope. Share an approximate product count and a short description of the import problem. No store password is needed to discuss the work.
